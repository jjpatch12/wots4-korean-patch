# Way of the Samurai 4 한국어 패치

《Way of the Samurai 4》 Steam PC판용 비공식 한국어 패치입니다.

## 지원 기준판

- 깨끗한 원본 게임 파일에서 설치 권장

## v6 패치 범위

| 구분 | 파일 수 | 적용 범위 |
|---|---:|---|
| ActionScript | 190 | 시스템 메시지, 선택지, 인터페이스 문자열 |
| Font | 2 | 한국어 글리프 및 굵은 인게임 글꼴 |
| GameText | 19 | 메뉴와 공통 게임 텍스트 |
| Script | 638 | 본편 대사, 이벤트 대사, NPC 대사, 전투 대사 |
| UI | 5 | 조작 설명 화면 `MANUAL00~04.nif` |
| **합계** | **854** | 배포 패치 파일 전체 |


## 설치 방법

1. [Releases](../../releases)에서 `WotS4_KoreanPatch_v6_OneClick_Bandizip.zip`을 받습니다.
2. 압축을 풀어 나온 `WotS4_KoreanPatch_v6_OneClick.bat`를 `WayOfTheSamurai4.exe`와 같은 게임 폴더에 넣습니다.
3. 게임을 완전히 종료합니다.
4. BAT를 실행하고 `1`을 선택합니다.

게임 폴더는 BAT 위치를 기준으로 자동 인식합니다.

## 원본 복구

같은 BAT를 다시 실행하고 `2`를 선택합니다. 최초 설치 때 저장한 원본 854개 파일이 복구됩니다.

원본은 게임 폴더의 숨김 폴더 `WotS4_KoreanPatch_Backup_OneClick_v6`에 최초 한 번만 저장되며 재설치해도 덮어쓰지 않습니다.
